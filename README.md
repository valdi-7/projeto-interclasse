# projeto-interclasse
📌 Sobre o projeto
Projeto base de um interclasse escolar. Cada partida tem dois times com 5 jogadores. Depois do jogo, basta digitar o placar (ex.: 1°ano 1 x 0 2°ano) e a tabela é atualizada sozinha, no estilo do Brasileirão.
✨ Funcionalidades
[x] Marcar partidas com o nome dos times e os 5 jogadores de cada um
[x] Ver os jogos do dia com os jogadores de cada time
[x] Registrar e editar o placar de cada jogo
[x] Tabela de classificação com pontos, jogos, vitórias, empates, derrotas, gols e saldo
[x] Dados salvos no navegador (localStorage)
[ ] Fase final (mata-mata)
[ ] Artilharia

🛠️ Tecnologias
HTML: estrutura da página
CSS: visual e layout
JavaScript: lógica das partidas, placar e tabela
